# Конфигурация PushDocs

`.pushdocs/config.json` хранится в репозитории и действует для выбранной ветки. Минимум: `{ "version": 1 }`. Все пути — от корня проекта.

## Основные поля

| Поле | Назначение и значение по умолчанию |
| --- | --- |
| `version` | Обязательно `1`. |
| `defaultLocale` | Основной язык, `ru`. |
| `documentRoots` | Папки документов: `["docs", "versioned_docs", "i18n"]`. |
| `editableFiles` | Дополнительные редактируемые файлы: `["sidebars.js", "sidebars.ts", ".pushdocs/config.json"]`. Markdown, MDX и JSON доступны отдельно. |
| `metadata` | Поля формы метаданных; стандартный набор указан ниже. |
| `media` | Настройки вложений; по умолчанию загрузка в `static/img`. |
| `templates` | Шаблоны документов, по умолчанию `[]`. |
| `preview` | Команды предпросмотра; необязательный объект. |

## Вложения

`media.images` задаёт хранилище изображений и MP4, необязательный `media.video` — отдельное хранилище видео. Без настройки `media` файлы загружаются в `static/img`. Отсутствующие папки создаются автоматически. Вложения остаются черновиками до отправки изменений в Git.

| Поле | Назначение и значение по умолчанию |
| --- | --- |
| `images.directory`, `video.directory` | Обязательная папка внутри соответствующего объекта, например `staticLocalized/{locale}/video`. |
| `images.publicUrl` | Публичный адрес изображений, `/{locale}/img`. |
| `video.publicUrl` | Публичный адрес видео, `/{locale}/video`. |
| `documentPathPrefixes` | Словарь префиксов статьи для удаления, например `{ "en": "en/" }`. По умолчанию `{}`. |
| `components` | Интеграции медиа-компонентов по JSX-имени. По умолчанию `{}`: имена `DocMedia` и `Video` сами по себе не включают интеграцию. |
| `components.<Name>.storage` | `"images"` для изображений и MP4 или `"video"` только для MP4. Определяет папку загрузки и фильтр галереи. Без хранилища `video` используется папка изображений. |
| `components.<Name>.srcBase` | Необязательная локальная база `src`, независимая от URL хранилища. Если задана, вставляется относительный путь от этой базы; иначе — публичный URL файла. |

Например, интеграция `DocMedia` задаётся как `"DocMedia": { "storage": "images", "srcBase": "/{locale}/img" }`, а `Video` — как `"Video": { "storage": "video" }` внутри `media.components`. Можно использовать другие JSX-имена с заглавной буквы. Полный [пример для Sendsay Docs](examples/sendsay-docs.pushdocs.json) включает хранилища и обе интеграции.

- В папке `{locale}` — код языка. В URL и `srcBase` сегмент основного языка опускается: `/video` и `/en/video`. Дополнительные языки определяются по файлам настроенных хранилищ.
- Порядок общей галереи: новые файлы → настроенные папки изображений по локалям → папки видео по локалям → «Другие файлы проекта». Основной язык идёт первым; пустые группы скрыты. Общая статика, включая `static/img` и `static/video`, входит в «Другие файлы проекта» даже при явном указании этих стандартных папок.
- Стандартная папка `static` сохраняет собственное отображение URL. Настройка `assets/pictures → /pictures` не переназначает адреса `static/img`. Если настроенный файл и файл из `static` опубликованы по одному URL, приоритет имеет настроенное хранилище; вставка перекрытого файла недоступна.
- При вставке к папке загрузки добавляется путь статьи без расширения. Поиск предзаполняется этой папкой и следует за её изменением. Очистите поиск, чтобы увидеть всю галерею. В общей галерее поиск изначально пустой.
- При выборе общей папки `static/` интерфейс предупреждает, что файл попадёт в сборку каждой локали. Подключение дополнительных папок к сборке сайта настраивается в самом сайте.

«Вставить вложение» создаёт Markdown: изображение для графического файла и ссылку для остальных типов. Выбор настроенного глобального медиа-компонента в меню открывает галерею и вставляет его JSX. Шаблоны с локальными импортами сохраняют обычную вставку целого шаблона. Глобальные компоненты обнаруживаются статическим разбором `src/theme/MDXComponents.{js,jsx,ts,tsx}` или `src/theme/MDXComponents/index.{js,jsx,ts,tsx}`. Динамический реестр не выполняется и не блокирует ручные шаблоны каталога.

Интеграция задаёт семантику JSX-имени для всего проекта. Локальный компонент с тем же именем должен соблюдать тот же контракт; граф импортов CMS не разрешает. При отсутствии интеграции пользовательский компонент показывается безопасным блоком. Внешние URL и явные пути `@site/` сохраняются как есть; относительный `src` разрешается от `srcBase`. Настройка базы не меняет реализацию компонента на самом сайте.

### Автодополнение путей

В исходнике Monaco подсказки появляются при вводе `/`, продолжении имени и по `Ctrl+Space`. Показываются дочерние папки и файлы; выбор папки продолжает навигацию. Поддерживаются относительные пути, пути от корня репозитория, `@site/`, `pathname:///` и `src` настроенных медиа-компонентов, включая многострочный JSX. Для публичных ссылок в подсказки не добавляется путь хранилища Git. Сегменты URL кодируются; суффиксы `?query` и `#anchor` сохраняются.

В режиме `storage: "video"` предлагаются папки и MP4. Для относительного `src` используется `srcBase`; для пустого полного `src` — публичная папка выбранного хранилища. Подсказки и поиск использований учитывают те же правила путей, что вставка и встроенный preview, без выполнения JavaScript репозитория.

MP4 доступен для воспроизведения в дереве файлов, а в галерее показывает видеокадр. Виртуализация и загрузка превью после остановки прокрутки описаны в [ADR-0005](adr/0005-attachment-gallery-virtualization.md).

## Метаданные

Каждый элемент `metadata`: `name` — уникальное имя поля, `label` — подпись, `type` — `string`, `number` или `boolean`. Максимум 50 полей.

По умолчанию: `title`, `description`, `slug` — строки; `sidebar_position` — число; `draft` — флаг. Пустой массив убирает поля формы.

## Шаблоны документов

Поля каждого элемента `templates`:

| Поле | Назначение |
| --- | --- |
| `id` | Идентификатор из строчных латинских букв, цифр и дефисов. |
| `label` | Название в меню. |
| `path` | Путь нового документа, например `docs/{slug}.mdx`. |
| `content` | Содержимое документа. |
| `companions` | Дополнительные файлы с `path` и `content`; по умолчанию `[]`. |
| `updates` | Изменения существующих файлов: `path`, `find`, `replace`. `find` должен встречаться ровно один раз. |

`id`, `label`, `path`, `content` обязательны. Подстановки `{slug}`, `{title}`, `{locale}` берутся из данных создания документа.

## Предпросмотр

Команды — массивы программы и аргументов.

| Поле | Значение по умолчанию |
| --- | --- |
| `preview.runtime` | `"default"` — профиль среды. |
| `preview.install` | `["yarn", "install", "--frozen-lockfile"]` |
| `preview.build` | `["yarn", "build"]` |
| `preview.start` | `["yarn", "start", "--host", "0.0.0.0", "--port", "{port}", "--no-open", "--poll", "1000"]` |
| `preview.output` | `"build"` — папка результата сборки. |

Без объекта `preview` стартовая команда та же, но без `--poll 1000`. `{port}` и `{host}` передаются отдельными аргументами и заменяются раннером.
