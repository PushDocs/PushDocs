# Изолированный предпросмотр черновиков

Предпросмотр собирает сайт из неизменяемого снимка Git и сохранённого набора изменений до коммита. Отдельный сервис получает исходники и запускает контейнер сборки без сети, секретов и Docker socket внутри контейнера. Web и основной worker не исполняют код сайта.

Оператор задаёт образ runtime, совместимый с lockfile проекта, и заранее наполняет кеш зависимостей. Команды установки и сборки берутся из конфигурации проекта, но выполняются только внутри ограниченного контейнера. Если зависимостей нет в кеше, сборка завершается ошибкой, а сеть автоматически не включается. Подготовка приватных зависимостей требует отдельного доверенного процесса оператора.

Каждый результат имеет отдельный origin и временную ссылку доступа. CMS проверяет членство перед выдачей ссылки. Ссылка действует как bearer credential, поэтому её нельзя публиковать или передавать посторонним. Сборка ограничена временем, памятью, CPU, числом процессов и размером снимка. Docker daemon относится к доверенной инфраструктуре и должен быть выделен для preview; контейнерная изоляция не заменяет отдельный хост для недоверенных команд.

Безопасность ограничений Docker проверяется на хосте с cgroup v2. Контейнеры не получают произвольные host mounts или настройки сети из репозитория. При отсутствии настроенного runner интерфейс объясняет причину, а быстрый Markdown-просмотр остаётся доступен.
