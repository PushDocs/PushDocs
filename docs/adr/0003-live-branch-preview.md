# Живой предпросмотр ветки

Статус: принято 16 сентября 2026 года.

PushDocs запускает локальный предпросмотр при открытии раздела «Документы». Предпросмотр использует выбранную ветку, сохранённые черновики и готовые вложения. Кнопка открывает сайт по адресу `http://213.148.1.118:<port>`.

Отдельный процесс `apps/preview` управляет checkout, установкой зависимостей и Docusaurus в режиме watch. Web создаёт аренду для каждой открытой вкладки. Вкладка обновляет аренду каждые 15 секунд и освобождает её при выходе из раздела. Runner завершает процесс после последней аренды. Истёкшая аренда позволяет завершить процесс после закрытия браузера или потери соединения.

Runner использует отдельный рабочий каталог для каждой пары проекта и ветки. При первом запуске он получает полный checkout текущего SHA и устанавливает зависимости. Затем он накладывает черновики и вложения из PushDocs. Новая ревизия набора изменений обновляет файлы в существующем каталоге, поэтому файловый watcher Docusaurus видит изменения. После выхода из «Документов» процесс останавливается, но checkout и зависимости остаются на диске. При повторном входе в ту же ветку с тем же SHA runner использует эту копию и заново сверяет черновики и вложения без Git fetch. Установка зависимостей повторяется только если изменились манифест, lockfile или команда установки. Новый SHA ветки требует нового checkout и перезапуска процесса. Неиспользуемые каталоги удаляются через семь дней.

Если загрузка ветки обрывается с временной ошибкой транспорта Git, runner повторяет `fetch` до трёх раз. Интерфейс показывает текущий этап запуска, включая повторную загрузку и установку зависимостей, а при сбое показывает уведомление с причиной. После перезапуска runner восстанавливает активные сессии, оставшиеся в БД со статусом `ready` или `starting`. Если аренда вкладки истекла во время деплоя, вкладка запрашивает её снова. HTTP-ответ с ошибкой не считается готовностью сайта.

Команды находятся в `.pushdocs/config.json`. Runner передаёт их в `spawn` как массив аргументов и не включает shell. Подстановки `{host}` и `{port}` разрешены только как отдельные аргументы. Docusaurus получает `0.0.0.0`, выделенный порт, `--no-open` и polling файлов.

Предпросмотр исполняет JavaScript репозитория. Установка должна считать подключённые проекты доверенными. Controller получает доступ к БД, Git и хранилищу вложений, но запускает установку зависимостей и каждый активный сайт под отдельным Unix пользователем. Пользователь сайта получает только свой рабочий каталог и ограниченный набор переменных среды. Runner сохраняет рабочий каталог после остановки процесса для быстрого повторного запуска. Preview container не получает Docker socket. Контейнер не заменяет отдельный хост для защиты от вредоносного кода.

Caddy автоматически публикует фиксированный диапазон `43000–43019` и проксирует каждый HTTP-порт на одноимённый порт runner во внутренней Compose-сети. Сам preview-runner не публикует порты хоста. Эти endpoints не проверяют сессию PushDocs.

Решение меняет прежний запрет на встроенную сборку из ADR 0001 и заменённого ADR 0002 только для явно запущенного локального предпросмотра. CI preview после отправки изменений остаётся отдельной функцией и продолжает подтверждать результат конкретного коммита.
